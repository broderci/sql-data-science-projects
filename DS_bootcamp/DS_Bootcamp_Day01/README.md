## 🛠️ Упражнения

### Упражнение 00 — `ex00/`
**Задача:** Знакомство с типами данных Python.  
**Файл:** `data_types.py`  
**Функция:** `data_types()`  
**Требования:** Создать 8 переменных разных типов и вывести их типы  
**Формат вывода:** `[int, str, float, bool, list, dict, tuple, set]`

### Упражнение 01 
**Задача:** Работа с файлами и преобразование форматов.  
**Файл:** `read_and_write.py`  
**Вход:** Файл `ds.csv` (данные о вакансиях)  
**Выход:** Файл `ds.tsv` с табуляцией вместо запятых  
**Особенность:** Сохранение данных без повреждения (учет запятых в содержимом)

### Упражнение 02 
**Задача:** Поиск в словарях по ключу.  
**Файл:** `stock_prices.py`  
**Данные:** Словари компаний и акций  
**Функция:** Поиск цены акции по названию компании  
**Обработка ошибок:** Unknown company для неизвестных компаний

### Упражнение 03 
**Задача:** Поиск по значению и ключу в словарях.  
**Файл:** `ticker_symbols.py`  
**Функция:** Поиск компании и цены по тикеру  
**Вывод:** "Tesla 724.88" для ввода "tsla"  
**Регистр:** Case-insensitive поиск

### Упражнение 04 
**Задача:** Преобразование структур данных.  
**Файл:** `to_dictionary.py`  
**Вход:** Список кортежей (страна, число)  
**Выход:** Словарь с числами как ключами, странами как значениями  
**Особенность:** Один ключ может иметь несколько значений

### Упражнение 05 
**Задача:** Универсальный поиск по компаниям и тикерам.  
**Файл:** `all_stocks.py`  
**Вход:** Строка с выражениями через запятую  
**Логика:** Автоматическое определение типа ввода (компания/тикер)  
**Вывод:** Форматированные результаты для каждого выражения

### Упражнение 06 
**Задача:** Сортировка словарей со сложными условиями.  
**Файл:** `dict_sorter.py`  
**Вход:** Данные стран и чисел  
**Сортировка:** По убыванию числа, затем по алфавиту страны  
**Вывод:** Только названия стран, по одному на строку

### Упражнение 07 
**Задача:** Работа с множествами для бизнес-задач.  
**Файл:** `marketing.py`  
**Данные:** 3 списка email-адресов (клиенты, участники события, получившие рассылку)  
**Задачи:**
- `call_center`: Клиенты, не видевшие промо-email
- `potential_clients`: Участники, не являющиеся клиентами
- `loyalty_program`: Клиенты, не участвовавшие в событии

### Упражнение 08 
**Задача:** Обработка строк и генерация документов.  
**Файлы:** `names_extractor.py`, `letter_starter.py`  
**Функции:**
- Извлечение имени и фамилии из email формата `name.surname@corp.com`
- Генерация таблицы сотрудников в TSV формате
- Создание персонализированных приветственных писем
**Технологии:** f-strings для форматирования

### Упражнение 09 
**Задача:** Реализация алгоритма шифрования.  
**Файл:** `caesar.py`  
**Алгоритм:** Шифр Цезаря с заданным сдвигом  
**Режимы:** `encode` (шифрование) и `decode` (расшифрование)  
**Обработка ошибок:** Поддержка только латинских символов

## 🎯 Приобретенные навыки

### Основы Python
- Работа с типами данных Python
- Понимание различий между mutable/immutable типами
- Использование `if __name__ == '__main__':` паттерна
- Организация кода в функции

### Структуры данных
- Работа со списками, кортежами, словарями и множествами
- Преобразование между разными структурами данных
- Сложная сортировка с несколькими критериями
- Использование множеств для операций над наборами данных

- Чтение и запись файлов разных форматов (CSV, TSV)
- Парсинг и извлечение информации из строк
- Автоматическая обработка данных в разных форматах
- Работа с аргументами командной строки

### Алгоритмы и шифрование
- Реализация шифра Цезаря
- Работа с символами и кодировками
- Валидация входных данных
- Обработка ошибок и исключений

### Практические применения
- Финансовые данные: работа с акциями и тикерами
- Маркетинговые задачи: анализ клиентских баз
- HR задачи: обработка данных сотрудников
- Безопасность: базовое шифрование данных
