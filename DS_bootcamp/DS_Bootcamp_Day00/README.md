# Day 00 — UNIX Command Line Tools for Data Science

**Тема:** Работа с UNIX командами для задач сбора и предобработки данных  
**Навыки:** Работа с командной строкой, обработка JSON/CSV, базовые инструменты ETL  
**Инструменты:** curl, jq, sort, uniq, sed, cat, shell scripting

---

## 📋 Обзор проекта

Этот проект посвящен освоению UNIX командной строки для базовых задач Data Science. В рамках проекта реализован ETL-пайплайн для работы с вакансиями HeadHunter API: от сбора данных до их очистки и анализа.

---

## 🛠️ Упражнения

### Упражнение 00 — `ex00/`
**Задача:** Создать shell-скрипт для сбора данных с HeadHunter API.  
**Скрипт:** `hh.sh`  
**Вход:** Название вакансии (например, "data scientist")  
**Выход:** `hh.json` с 20 вакансиями в читаемом JSON формате  
**Инструменты:** curl, jq

### Упражнение 01 — `ex01/`
**Задача:** Преобразование JSON в CSV формат.  
**Скрипты:** `json_to_csv.sh`, `filter.jq`  
**Вход:** `hh.json`  
**Выход:** `hh.csv` с колонками: id, created_at, name, has_test, alternate_url  
**Инструменты:** jq

### Упражнение 02 — `ex02/`
**Задача:** Сортировка CSV файла.  
**Скрипт:** `sorter.sh`  
**Вход:** `hh.csv`  
**Выход:** `hh_sorted.csv`, отсортированный по created_at, затем по id  
**Инструменты:** sort, cat, head, tail

### Упражнение 03 — `ex03/`
**Задача:** Очистка и извлечение информации из названий вакансий.  
**Скрипт:** `cleaner.sh`  
**Вход:** `hh_sorted.csv`  
**Выход:** `hh_positions.csv` с извлеченными уровнями (Junior/Middle/Senior)  
**Логика:** Извлечение уровня из названия, замена на "-" если уровень не найден

### Упражнение 04 — `ex04/`
**Задача:** Описательная статистика по уровням позиций.  
**Скрипт:** `counter.sh`  
**Вход:** `hh_positions.csv`  
**Выход:** `hh_uniq_positions.csv` с подсчетом уникальных уровней  
**Статистика:** Количество вакансий по каждому уровню (Junior/Middle/Senior)

### Упражнение 05 — `ex05/`
**Задача:** Разделение и объединение данных по датам.  
**Скрипты:** `partitioner.sh`, `concatenator.sh`  
**Функции:**
- Разделение данных по датам создания (по created_at)
- Объединение разделенных файлов обратно в один
**Цель:** Демонстрация работы с партиционированием данных

## 🚀 Практическое применение

Проект демонстрирует реальный сценарий работы дата-инженера:
1. **Сбор данных** из внешнего источника (API)
2. **Трансформация** в удобный формат (JSON → CSV)
3. **Очистка** и извлечение полезных признаков
4. **Анализ** для понимания структуры данных
5. **Организация** данных для хранения (партиционирование)
