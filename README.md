# SQL, BSA & Data Science Learning Projects

Этот репозиторий содержит мои учебные и практические проекты по SQL, бизнес-системному анализу (BSA) и Data Science, выполненные в рамках интенсивного обучения. Проекты демонстрируют прогресс от базовых SQL-запросов до продвинутых тем анализа данных, включая понимание бизнес-контекста и системного мышления.

## 🛠️ Технологический стек

### Базы данных и SQL
- **PostgreSQL** — продвинутые SQL запросы и оптимизация производительности
- **SQL** — полный спектр: DDL, DML, DQL, сложные аналитические запросы
- **PL/pgSQL** — процедурные расширения, триггеры, пользовательские функции
- **Транзакции** — уровни изоляции, управление конкурентным доступом

### Бизнес- и системный анализ
- **Моделирование** — BPMN, UML (диаграммы классов, состояний), ER-диаграммы
- **Управление требованиями** — трассировка, приоритизация, WEEEK/Jira
- **Проектирование** — wireframes, Use Case, User Stories
- **Интеграция** — REST API, маппинг данных, обработка ошибок
- **Качество** — тест-кейсы, нефункциональные требования, логирование

### Python для Data Science
- **Python 3** — полный стек от базового синтаксиса до production практик
- **ООП в Python** — классы, наследование, полиморфизм, инкапсуляция
- **Виртуальные окружения** — venv, pip, requirements.txt, управление зависимостями
- **Веб-скрапинг** — BeautifulSoup4, requests, парсинг HTML/XML
- **Профилирование** — cProfile, pstats, оптимизация производительности
- **Тестирование** — pytest, модульное тестирование, покрытие кода
- **Эффективные практики** — list comprehensions, map/filter/reduce, генераторы, Counter

### Инструменты и утилиты
- **UNIX/Linux** — командная строка, shell scripting, обработка текста
- **Git** — контроль версий, управление проектами, collaboration
- **ETL инструменты** — curl, jq, sed, awk для обработки данных
- **Визуализация** — termgraph для графиков в терминале

### В процессе изучения 🔜
- pandas/numpy — анализ и обработка табличных данных
- matplotlib/seaborn — визуализация данных и создание графиков
- scikit-learn — алгоритмы машинного обучения
- Статистика — анализ данных и тестирование гипотез

## 📊 Приобретенные навыки

### Работа с базами данных
- **Проектирование БД** — нормализация, создание схем, определение отношений
- **Сложные запросы** — многоуровневые JOIN, оконные функции, рекурсивные запросы
- **Оптимизация** — создание индексов, анализ планов запросов, настройка производительности
- **Транзакции** — управление ACID свойствами, изоляция, конкурентный доступ
- **Бизнес-логика** — реализация на уровне БД через функции и триггеры

### Бизнес-анализ
- **Выявление требований** — интервью, воркшопы, анализ стейкхолдеров
- **Моделирование процессов** — BPMN, DFD, swimlane-диаграммы
- **Системное мышление** — контекстные диаграммы, границы системы
- **Документирование** — BRD, глоссарии, реестры требований
- **Управление качеством** — тест-кейсы, отчеты о дефектах

### Python программирование
- **Фундамент** — типы данных, структуры, управляющие конструкции
- **ООП** — проектирование классов, наследование, композиция, полиморфизм
- **Работа с файлами** — CSV, JSON, TSV, бинарные форматы
- **Алгоритмы** — реализация шифров, сортировок, поисковых алгоритмов
- **Производственные практики** — логирование, обработка ошибок, конфигурация
- **Эффективность кода** — оптимизация времени выполнения и использования памяти

### Data Engineering
- **ETL пайплайны** — сбор, преобразование, загрузка данных
- **Веб-скрапинг** — парсинг веб-страниц, извлечение структурированных данных
- **Обработка данных** — очистка, трансформация, агрегация
- **Автоматизация** — shell-скрипты, планировщики задач, мониторинг
- **Воспроизводимость** — виртуальные окружения, управление зависимостями

### Профессиональные практики
- **Тестирование** — модульные тесты, покрытие кода, TDD подход
- **Профилирование** — анализ производительности, оптимизация ресурсов
- **Документация** — README файлы, комментарии, схемы архитектуры
- **Управление проектами** — Git workflow, ветвление, code review
- **Интеграция** — REST API, работа со смежными системами
