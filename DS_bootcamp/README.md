# Кластер проектов по DS (Data Science)

Этот каталог содержит результаты учебного трека по науке о данных.  
Проекты выстроены в логической последовательности: от работы с командной строкой и основами Python до продвинутых техник оптимизации кода, управления пакетами и тестирования.

> **Важно:** Модули логичнее проходить по порядку, так как каждый следующий день может опираться на знания и навыки, полученные в предыдущих.

---

## Структура кластера

### Day 00 — UNIX Command Line Tools

**Фокус модуля:** базовые инструменты командной строки UNIX для сбора и предобработки данных: `curl`, `sort`, `uniq`, `jq`, `sed`, `cat`.

**Задачи:**
- Парсинг API HeadHunter с помощью `curl` и `jq`.
- Преобразование JSON в CSV.
- Сортировка данных.
- Очистка и нормализация текстовых полей.
- Подсчёт уникальных значений.
- Разделение и объединение файлов по датам.

**Ключевые навыки:** работа с API, обработка JSON, написание shell-скриптов.

---

### Day 01 — Intro to Python: Syntax and Semantics

**Фокус модуля:** основы синтаксиса и семантики Python: типы данных, работа с файлами, словари, множества, строки.

**Задачи:**
- Объявление переменных разных типов.
- Чтение и запись файлов (CSV → TSV).
- Поиск по ключам и значениям в словарях.
- Работа со списками кортежей и преобразование в словари.
- Операции с множествами (marketing-задачи).
- Извлечение данных из email-адресов.
- Реализация шифра Цезаря.

**Ключевые навыки:** базовый синтаксис Python, работа со структурами данных, обработка аргументов командной строки.

---

### Day 02 — Intro to Python: OOP skills

**Фокус модуля:** объектно-ориентированное программирование в Python: классы, методы, конструкторы, наследование, вложенные классы, конфигурация и логирование.

**Задачи:**
- Создание простого класса для чтения файла.
- Добавление методов и конструктора.
- Валидация структуры данных.
- Создание вложенных классов для вычислений.
- Наследование и расширение функциональности.
- Вынос конфигурации в отдельный файл.
- Логирование всех методов.
- Отправка уведомлений в Telegram.

**Ключевые навыки:** ООП-дизайн, модульность, обработка исключений, логирование.

---

### Day 03 — Intro to Python: Package management and virtual environment

**Фокус модуля:** управление пакетами и виртуальными окружениями: `virtualenv`, `pip`, `requirements.txt`, профилирование, тестирование.

**Задачи:**
- Создание и активация виртуального окружения.
- Установка пакетов (`termgraph`, `BeautifulSoup`, `pytest`).
- Генерация `requirements.txt`.
- Парсинг Yahoo Finance с BeautifulSoup.
- Профилирование кода с `cProfile` и `pstats`.
- Оптимизация HTTP-запросов.
- Написание unit-тестов с PyTest.

**Ключевые навыки:** изоляция окружений, управление зависимостями, веб-скрапинг, профилирование, тестирование.

---

### Day 04 — Intro to Python: Efficient code practices

**Фокус модуля:** написание эффективного кода: list comprehensions, `map`, `filter`, `reduce`, `Counter`, генераторы.

**Задачи:**
- Сравнение производительности циклов, list comprehensions и `map`.
- Фильтрация данных с `filter`.
- Вычисление суммы квадратов с `reduce`.
- Подсчёт частот с `Counter`.
- Измерение использования памяти с генераторами против обычных списков (на датасете MovieLens).

**Ключевые навыки:** оптимизация времени выполнения, оптимизация памяти, профилирование ресурсов.

---

## Типы артефактов в кластере

- **Скрипты (Python / Shell):**
    - исполняемые файлы с функциями и обработкой аргументов,
    - модули с классами и методами,
    - тестовые скрипты (PyTest).
- **Конфигурационные файлы:**
    - `requirements.txt` — список зависимостей,
    - `config.py` — вынесенные параметры.
- **Данные:**
    - JSON, CSV, TSV-файлы — результаты обработки,
    - логи (`analytics.log`),
    - архивы виртуальных окружений.
- **Отчёты о профилировании:**
    - текстовые файлы с результатами `cProfile` и `pstats`.
- **Визуализации:**
    - графики в терминале (`termgraph`).

---

## Как читать этот кластер

1. **Основы инструментария (Day 00):** начните с командной строки — это база для многих задач DS.
2. **Погружение в Python (Day 01–02):** изучите синтаксис, структуры данных и ООП.
3. **Экосистема Python (Day 03):** научитесь управлять зависимостями, профилировать и тестировать код.
4. **Мастерство эффективности (Day 04):** освойте техники оптимизации времени и памяти.

Такой подход позволит вам последовательно пройти путь от сбора данных до написания чистого, быстрого и тестируемого кода.
